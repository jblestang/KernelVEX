## 1. Linux Kernel, Kbuild & Git Internals

- **Catch & Fix — Partial clone vs `:ro` checkout (`Section 4.1`–`4.2`):**
  - *Initial draft issue:* `HOWTO.md` initially combined `git clone --bare --filter=blob:none` (with no initial checkout/archive) with `-v kernelvex-sources:/sources:ro` and `-e GIT_NO_LAZY_FETCH=1`. A freshly created blobless clone contains zero working-tree blobs, so `git checkout --detach v6.12.11` would fail when lazy fetching is disabled or the source mount is read-only. In addition, `git clone --bare` omits `remote.origin.fetch`, preventing branch updates on subsequent fetches.
  - *Resolution applied:* Switched the primary source volume workflow in [`HOWTO.md`](file:///Users/jean-baptiste/KernelVEX/HOWTO.md) to `git clone --mirror` + `git remote update --prune` + `git commit-graph write --reachable --changed-paths`, verified inside `localhost/kernelvex:local` to work cleanly with `git clone --shared --no-checkout` and `git describe --abbrev=0`, and isolated the `--filter=blob:none` + `GIT_NO_LAZY_FETCH=1` instructions into an explicit tip noting that target tag blobs must be prefetched (`git archive <tag> >/dev/null`) before locking the mount `:ro`.
- **Kernel config & version handling:**
